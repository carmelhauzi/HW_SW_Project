The hardware sends the 7 spheres one after another through one intersection pipeline. The pipeline should be able to accept a new sphere every clock, so different spheres can be in different pipeline stages at the same time.

For each sphere, calculate the same math as Sphere.intersectionTime:
cp = center - ray.point / v = cp dot ray.vector / cpcp = cp dot cp / disc = radius_squared - cpcp + v*v
